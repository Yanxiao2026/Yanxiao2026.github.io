# 三星堆 · 沉睡三千年，一醒惊天下

「第一章」单页网站：以一个滚动式长页讲述三星堆遗址的故事，包含概述、文物、未解之谜、参观信息等章节。

## 在线访问

- GitHub Pages：<https://yanxiao2026.github.io/>

## 本地预览

无需任何构建步骤，用 Python 自带的 HTTP 服务即可：

```bash
# 在仓库根目录执行（Python 3）
python -m http.server 8000
# 然后浏览器打开 http://127.0.0.1:8000/
```

> 页面通过相对路径引用 `assets/` 下的图片，请勿直接双击 `index.html` 打开（`file://` 协议下部分资源可能无法加载），建议始终经本地服务器预览。

## 目录结构

```
index.html      # 唯一页面：内容、样式与交互脚本都在这一个文件里
assets/         # 首页引用的全部图片（首屏背景、文物照片、纹样符号等）
.gitignore      # 排除制作过程中的临时文件与本地凭证
```

## 分支

- `main`：唯一开发与发布分支，推送到 `main` 后 GitHub Pages 自动重新构建。
